Machine and operator QA

What the data says

Each finding is calculated from the loaded tests, and says how sure it is. Findings marked in amber need a decision.

Machines side by side

Does one machine or operator read differently?

Strength is compared after allowing for mix and age at break, so a machine that mostly breaks stronger concrete is not blamed for it.

Has any machine drifted over time?

Each point is one set of specimens, shown as how far it broke from what its mix and age predict. A machine that drifts would trend up or down, or run on one side of its centre line.

Calibration

Calibration dates, intervals and constants from the machine records, set against when and how hard each machine was used.

Data and settings

Settings

The default 395 days is 13 months. Use the interval your accreditation or method requires.

Accepted files

Database export

One workbook with sheets, or one CSV per table, named Results, Specimen, SampleSet, Sample and Setup (required). ForneyUser, Machine, FrameCalibration and MachineTuningParams add operators, capacity and calibration. Only compression cylinders are used.

Flat table

One row per specimen with date, age_days, strength_psi and machine required. operator, mix, set_id, sample, max_load_lbf and ramp_psi_per_s are optional. The template has the exact headers. Calibration needs the database export.
